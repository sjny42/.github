## Nest Organization 입니다.

네스트(Nest)는 영어로 '둥지' 또는 '보금자리'를 뜻하는 단어로, OSS 생태계와 자기개발을 위한 둥지를 의미합니다.
각 구성원이 원하는 방향으로 나가기 위한 툴, 기술 공유를 진행합니다.
